# Installed-game fixtures

The installed suite compares selected Hacker and turret behaviors with original INI declarations, and checks module-registration order against output generated by the pinned C++ source. The fixture script reads the player's original `INIZH.big` to prepare these five files under the external runtime's `test-fixtures/` directory.

| File | Input |
| --- | --- |
| `hacker.ini` | Original China Hacker `HackInternetAIUpdate` module and its Object wrapper. |
| `hacker-disable.ini` | Original Hacker ability modules and SpecialPower declaration. |
| `turret-fixtures.ini` | Selected base-faction primary turret blocks and their Object and AI behavior wrappers. |
| `module-metadata/installed.ini` | Original Object declarations for a fixed roster, including the default and required parents. |
| `module-metadata/installed-r2.native.tsv` | Registration order measured by executing extracted native C++ methods and factories against that roster. |

The native comparison covers ModuleInfo filtering and inheritance, add/remove/replace operations, interface masks and factory resolution. The script checks the five files against expected SHA-256 hashes, so a different archive or generated result may fail validation.

## Prepare the fixtures

Use Python 3.11 or later, Git, a C++17 compiler and the clean [pinned source checkout](../reference/PROVENANCE.md). From the repository root, pass the two archives from your Zero Hour installation. Choose a new output directory outside the checkout.

```sh
python3 -B tests/installed/prepare-metadata.py \
  --archive "../private/GameData/Command and Conquer Generals Zero Hour/INIZH.big" \
  --maps-archive "../private/GameData/Command and Conquer Generals Zero Hour/MapsZH.big" \
  --source ../private/references/GeneralsGameCode \
  --output ../private/installed-runtime
```

The script defaults to `clang++`. Use `--cxx PATH` to select another compiler. It keeps the generated C++ and native output alongside `test-fixtures/`. An optional `--compare PATH` checks the new files against an existing `test-fixtures/` directory as well.

The `--maps-archive` option is needed for the custom map chooser checks. It copies the original Tournament Desert map and preview into twelve numbered entries under `UserData/Maps/` to exercise scrolling and selection. The generated `MapCache.ini` uses paths tied to the output location. Keep that directory in place as the runtime and follow the [installed-game setup](../README.md#installed-game-checks) to attach the original installations and run the suite.

The native Repair Pad check uses a declared custom map because the original skirmish maps have no `TechRepairPad` placements. Generate it after preparing the runtime above. The script copies the owned Hostile Dawn map and changes its single `TechRepairbay` placement to `TechRepairPad`, retaining the position, orientation, object properties, terrain and scripts. It clears the copy's `WorldInfo` title tag so the chooser uses the custom filename and keeps it alongside the official map. Rerunning the script updates the previously generated fixture if its bytes match the known older version.

```sh
python3 -B tests/installed/prepare-repair-pad.py \
  --maps-archive "../private/GameData/Command and Conquer Generals Zero Hour/MapsZH.big" \
  --runtime-root ../private/installed-runtime
```
